# PSO2 装備シミュレーター

日本語 | [简体中文](README_CN.md)

PSO2クラシック向けの、オフラインで使える装備・ダメージシミュレーターです。

<img width="1890" height="1652" alt="image" src="https://github.com/user-attachments/assets/ecc28cc8-333d-4e69-82d7-0f567923b454" />


## 主な機能

- クラス・レベル、攻撃方法、敵防御力、部位倍率を設定。
- 武器、防具、リング、特殊能力、S級特殊能力を編集。
- マグ、ドリンク、各種バフを設定し、ダメージ期待値とDPSを比較。
- 構成保存、カスタム能力、JSONの書き出し・読み込み。
- コンパクト表示、日本語・中国語、システム連動／ライト／ダーク配色。

## 使い方

`index.html` をダウンロードしてブラウザーで開くだけで利用できます。インストールは不要です。

クラスと攻撃方法を選び、装備や発動条件を調整すると計算結果が更新されます。別の端末へ移すときは装備データを書き出してください。

DPSは選択した攻撃を繰り返す場合の概算です。PP回復のための中断や実戦の攻撃ローテーションは含みません。
