# PSO2 装備シミュレーター

日本語 | [中文](README_CN.md)

PSO2 クラシック向けの非公式装備・ダメージシミュレーター。日本語・中国語対応、オフラインで利用できます。

## 主な機能

- クラス・レベル・敵防御力・部位倍率を設定
- 武器・ユニット・リング・特殊能力・S級特殊能力を編集
- 通常攻撃・PA・テクニックのダメージ期待値とDPSを計算
- 6武器シリーズとカスタム装備を比較（S4：累加追撃に対応）
- 設定の自動保存、装備データのJSONインポート・エクスポート

## 使い方

`index.html` をダウンロードし、ブラウザーで開いてください。インストールは不要です。

クラスと攻撃方法を選び、装備・発動条件を調整すると結果が更新されます。データを別の環境へ移す際は、装備データをエクスポートしてください。

## 計算について

DPSは選択した攻撃を繰り返す場合の概算です。PP回復のための中断や実戦の攻撃ローテーションは含みません。未対応効果・未確認の動作時間は画面内に表示します。
