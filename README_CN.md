面向 PSO2 旧国的非官方配装与伤害模拟器，支持中日切换，可离线使用。

## 主要功能

- 设置职业、等级、敌人防御力与部位倍率
- 编辑武器、防具、戒指、普通能力与 S 能力
- 计算普攻、PA、法术的伤害期望与秒伤
- 比较六系列武器和自定义配装，支持 S4 累加追击
- 自动保存设置，支持 JSON 配装导入与导出

## 使用方法

下载 `index.html`，使用浏览器打开，无需安装。

选择职业与攻击方式，调整装备和触发条件，即可查看结果。需要转移到其他环境时，请先导出配装存档。

## 计算说明

秒伤为重复当前动作的近似结果，不包含回 PP 停手及实战连招循环。尚未支持的效果和待确认的动作时间会在界面中提示。
