# PSO2 旧国配装模拟器

[日本語](README.md) | 简体中文

面向 PSO2 旧国的离线配装与伤害模拟器。

## 主要功能

- 设置职业等级、攻击方式、敌人防御力与部位倍率。
- 编辑武器、防具、戒指、普通能力和 S 能力。
- 设置玛古、饮料和增益，比较伤害期望与 DPS。
- 方案保存、自定义能力与 JSON 导入导出。
- 紧凑排版、中日文切换、跟随系统／浅色／深色配色。

## 使用方法

下载 `index.html`，用浏览器直接打开，无需安装。

选择职业与攻击方式，调整装备和触发条件即可查看结果。需要跨设备转移时，请先导出配装数据。

DPS 是重复当前动作的近似结果，不包含回 PP 停手和实战连招循环。
